# 森林侦探

面向幼儿的原创思维探险 PWA，包含十五章、九十个任务。前十一章练习观察、规律、路线、分配、关系推理和图形变化；第十二章「溪谷引水园」旋转水渠、连接水路；第十三章「松果称量屋」观察天平、等量替换；第十四章「花窗拼图坊」翻动图案、兼顾局部与整体；第十五章「萤火开关屋」组合开关、观察变化抵消。第三至十五章采用千问 Cherry，全站共 455 段中文配音。支持触控、离线课程、分章进度和备份。

## iPad 安装

Safari 打开 https://codexiongan.com/forest-detective/ ，分享 → 添加到主屏幕。从主屏幕进入，点击「下载十五章」。下载完成后可断网使用，无需 Windows 电脑保持开启。

已安装旧版的设备：联网返回营地，打开家长手册，等待更新下载完成后点击「应用已下载的新版本」。以前章节的进度会自动保留；不要清除网站数据。

进入每个关卡自动播放配音。右上角「声音开 / 声音关」控制声音；「听一听」可重复听题。学习记录只保存在当前设备，家长手册提供导出和恢复。

## 发布

仓库 Settings → Pages → Source 选择 Deploy from a branch，分支 main，目录 / (root)。更新 main 分支后自动发布。

本仓库只包含可发布的静态文件。课程更新时须同时更新 precache.js 中的资源版本与清单。不要在此仓库上传个人资料或学习进度备份。
