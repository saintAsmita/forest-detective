# 森林侦探

面向幼儿的原创思维探险 PWA，包含两章、十二个任务：第一章「胡萝卜失踪事件」练习观察分类、证据和路线推理；第二章「月光列车」练习重复规律、补全、纠错、数量变化与二维规则。共 52 段中文童趣配音，支持触控、离线课程、分章进度和备份。

## iPad 安装

Safari 打开 https://codexiongan.com/forest-detective/ ，分享 → 添加到主屏幕。从主屏幕进入，点击「下载两章」。下载完成后可断网使用，无需 Windows 电脑保持开启。

已安装旧版的设备：联网返回营地，打开家长手册，等待更新下载完成后点击「应用已下载的新版本」。第一章旧进度会自动保留；不要清除网站数据。

进入每个关卡自动播放配音。右上角「声音开 / 声音关」控制声音；「听一听」可重复听题。学习记录只保存在当前设备，家长手册提供导出和恢复。

## 发布

仓库 Settings → Pages → Source 选择 Deploy from a branch，分支 main，目录 / (root)。更新 main 分支后自动发布。

本仓库只包含可发布的静态文件。课程更新时须同时更新 precache.js 中的资源版本与清单。不要在此仓库上传个人资料或学习进度备份。
