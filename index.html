带到 iPad 上

  1. 通过 HTTPS 地址，用 Safari 打开。
  2. 分享 → 添加到主屏幕，再从主屏幕打开。
  3. 点击“下载十一章”，等到显示“十一章已下载”。
  4. 打开飞行模式，退出后重开，确认图片、配音和关卡都可使用。

Windows 上的 localhost 可以测试离线；iPad 访问电脑的普通 HTTP 地址只能在线试玩。正式离线使用需要 HTTPS。清理网站数据会删除进度和课程，请保存备份。
